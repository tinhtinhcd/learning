# 1. Why ClassLoader Matters

Everything in Java starts with class loading.

```text
.class
  ↓
ClassLoader
  ↓
JVM Memory
  ↓
Execution
```

Frameworks depending heavily on ClassLoader:

- Spring
- Hibernate
- Tomcat
- JUnit

---

# 2. Class Loading Lifecycle

```text
Loading
 ↓
Linking
 ├ Verification
 ├ Preparation
 └ Resolution
 ↓
Initialization
 ↓
Usage
 ↓
Unloading
```

Interview favorite topic.

---

# 3. Bootstrap ClassLoader

Loads core JDK classes.

Examples:

```java
java.lang.String
java.util.List
```

Top of hierarchy.

---

# 4. Platform ClassLoader

Loads platform modules.

Examples:

```text
jdk.*
javax.*
```

---

# 5. Application ClassLoader

Loads:

```text
Application classes
Third-party libraries
```

Examples:

```text
Spring Boot
Hibernate
Jackson
```

---

# 6. Parent Delegation Model

Loading order:

```text
Application
 ↓
Platform
 ↓
Bootstrap
```

Advantages:

- Security
- Avoid duplicate classes
- Consistent behavior

---

# 7. Class Identity

A class is uniquely identified by:

```text
Class Name
+
ClassLoader
```

Important interview topic.

---

# 8. Class Unloading

Class unloading occurs when:

- ClassLoader becomes unreachable
- No loaded classes are referenced

Rare in standard applications.

---

# 9. Custom ClassLoader

Example:

```java
class MyClassLoader extends ClassLoader {
}
```

Use Cases:

- Plugin systems
- Application servers
- Script engines

# 10. Reflection Overview

Reflection allows runtime inspection.

Capabilities:

```text
Inspect Classes
Create Objects
Invoke Methods
Access Fields
```

---

# 11. Obtaining Class Objects

```java
User.class
```

```java
user.getClass()
```

```java
Class.forName("User")
```

---

# 12. Creating Objects via Reflection

```java
Class<?> clazz = User.class;
Object obj = clazz.newInstance();
```

Modern approach:

```java
clazz.getDeclaredConstructor()
     .newInstance();
```

---

# 13. Invoking Methods via Reflection

```java
Method method =
    clazz.getMethod("save");

method.invoke(obj);
```

---

# 14. Accessing Fields

```java
Field field =
    clazz.getDeclaredField("name");
```

```java
field.setAccessible(true);
```

---

# 15. Reflection Drawbacks

- Slower than direct invocation
- Less type safety
- Harder debugging

# 19. CGLIB Overview

Works without interfaces.

```text

```

# 20. JDK Proxy vs CGLIB

JDK Proxy:

```text
Requires Interface
```

CGLIB:

```text
Subclass Based
```
