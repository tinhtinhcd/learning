# Part I. The Evolution of Databases

## Traditional RDBMS

Advantages:

- ACID transactions
- Strong consistency
- Rich SQL ecosystem
- Data integrity

Challenges:

- Horizontal scaling is difficult
- Rigid schema evolution
- Global distribution complexity
- High write throughput limitations

---

# Part II. Why NoSQL?

NoSQL databases emerged to address:

- Internet-scale workloads
- Massive write volumes
- Flexible schemas
- Geo-distributed systems
- Low-latency access

Examples:

- Social Networks
- E-Commerce
- IoT Platforms
- Event Streaming Systems

---

# Part III. CAP Theorem

## Three Properties

### Consistency

All clients see the same data.

### Availability

Every request receives a response.

### Partition Tolerance

System continues operating despite network failures.

---

## CP Systems

Prioritize:

```text
Consistency
+
Partition Tolerance
```

Examples:

- MongoDB
- HBase

---

## AP Systems

Prioritize:

```text
Availability
+
Partition Tolerance
```

Examples:

- Cassandra
- DynamoDB

---

# Part IV. Consistency Models

## Strong Consistency

Latest write always visible.

## Eventual Consistency

Replicas converge over time.

## Read-Your-Own-Writes

Users can immediately see their own changes.

## Causal Consistency

Preserves causal ordering.
